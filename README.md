# DevOps System Automation

A beginner-friendly Bash automation project built in Ubuntu WSL.

## What This Project Does

This project automates basic system administration tasks using Bash.

### Features

- System health checks
- Disk usage monitoring
- Memory usage monitoring
- System uptime checks
- Process monitoring
- Automated report generation
- Project backup automation

## Project Structure

```text
devops-system-automation/
├── scripts/
│   ├── system-health.sh
│   └── backup.sh
├── reports/
├── backups/
├── logs/

How to Run

Make the scripts executable:

chmod +x scripts/*.sh

Run the health check:

./scripts/system-health.sh

Run the backup:

./scripts/backup.sh
